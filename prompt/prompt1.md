Vamos começar a Etapa 1 do nosso jogo estilo Tetr.io. 
Por favor, crie a estrutura inicial de um projeto Next.js (App Router) com Tailwind CSS e configure um componente principal utilizando HTML5 Canvas para rodar o motor do Tetris.

Requisitos desta etapa:
1. Estrutura limpa de pastas do Next.js.
2. Motor de Tetris rodando fluidamente (60 FPS):
   - Sistema de Rotação SRS (Super Rotation System) com wall kicks.
   - Peça fantasma (Ghost Piece) indicando onde a peça vai cair.
   - Mecânica de "Hold" (guardar peça).
   - Gravidade progressiva, detecção de colisão e fim de jogo (Game Over).
   - Linhas limpas gerando pontuação básica.
3. Controles responsivos pelo teclado (Setas/WASD, Espaço para hard drop, Shift para hold).
